My personal page — a GitHub pull request, rendered as a portfolio.

## About

I'm Daniel Almeida, a high-ownership Senior Fullstack Engineer. I sit close to
product, ship in production, and treat review as part of the work — not a gate
after it. Based in Brazil, working remote.

This page reimagines my resume as a GitHub PR you can review: read the
conversation, walk the commits, check the CI, and open the diff. Approve and
merge to send me a mail.

## How I work

I write for the next reviewer: small diffs, named decisions, tests that fail for
a reason. I use AI to go faster at the edges — boilerplate, first-pass review,
scaffolding — and keep judgment on the path that hits production.

## Tech

Single-page site built with plain HTML and CSS. SVG icons inline, no external
libraries. Styled after GitHub's light theme.
